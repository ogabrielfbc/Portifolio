NEXUS TECH

Uma loja virtual desenvolvida com PHP e MySQL, com sistema de usuários, produtos e compras.

Galeria do projeto

Sobre o projeto

O NEXUS TECH é um projeto pessoal de desenvolvimento de uma loja virtual. A proposta é criar uma plataforma na qual os usuários possam acessar suas contas, visualizar produtos e utilizar um carrinho de compras.

Funcionalidades

  • Cadastro e login de usuários.
  • Catálogo de produtos.
  • Carrinho de compras.
  • Sistema de NEXUS Coins.
  • Gerenciamento de informações com banco de dados.

Tecnologias utilizadas

PHP MySQL HTML CSS JavaScript
