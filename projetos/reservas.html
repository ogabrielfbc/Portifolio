Sistema de Reservas

Aplicação desenvolvida para facilitar o agendamento e o gerenciamento de reservas de laboratórios, considerando datas, horários e disponibilidade.

Galeria do projeto

Sobre o projeto

O Sistema de Reservas é uma aplicação desenvolvida em Python com Streamlit e MySQL. Seu objetivo é facilitar a organização de reservas de laboratórios, permitindo registrar agendamentos e consultar informações de disponibilidade.

Funcionalidades

  • Criação de novas reservas.
  • Seleção de laboratório.
  • Escolha de data e horário.
  • Verificação de conflitos entre reservas.
  • Consulta das reservas cadastradas.

Tecnologias utilizadas

Python Streamlit MySQL
