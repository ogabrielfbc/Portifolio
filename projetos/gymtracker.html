GymTracker

Projeto de programação voltado à organização e ao acompanhamento de atividades relacionadas a treinos.

Imagem do projeto

Sobre o projeto

O GymTracker é um projeto de programação que tem como objetivo auxiliar na organização e no acompanhamento de atividades relacionadas a treinos. A proposta é aplicar conhecimentos de programação na criação de uma solução para esse contexto.

Objetivos do projeto

  • Aplicar conhecimentos de programação em Python.
  • Praticar lógica de programação.
  • Desenvolver uma solução voltada à organização de treinos.

Tecnologia utilizada

Python
