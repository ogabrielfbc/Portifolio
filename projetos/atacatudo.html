Galeria do projeto

Sobre o projeto

O AtacaTudo é um sistema desenvolvido em Java, com interface gráfica, para organizar diferentes informações de um estabelecimento comercial. O projeto reúne telas e funcionalidades relacionadas ao controle de estoque, fornecedores e gerenciamento de contas.

Funcionalidades

  • Tela de login e cadastro de usuários.
  • Menu principal de navegação.
  • Gerenciamento de estoque.
  • Cadastro e consulta de fornecedores.
  • Alertas de reposição de produtos.
  • Gerenciamento de conta.

Tecnologias utilizadas

Java Java Swing Maven
