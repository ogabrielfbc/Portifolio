# Portfólio — Gabriel Batista

Olá! Meu nome é Gabriel Batista e sou estudante do Ensino Médio Técnico em Tecnologia da Informação.

Este repositório contém meu portfólio pessoal, desenvolvido para apresentar meus conhecimentos, projetos, experiências acadêmicas e minha evolução na área de tecnologia.

## Sobre o projeto

O portfólio foi desenvolvido com o objetivo de apresentar minhas habilidades e projetos de maneira organizada, moderna e responsiva, reunindo em um único lugar informações sobre minha trajetória e meus conhecimentos em tecnologia.

Além da apresentação pessoal, o projeto conta com uma área administrativa para gerenciamento das mensagens recebidas pelo formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- LocalStorage API
- EmailJS (integração opcional)

## Projetos apresentados

O portfólio reúne alguns dos projetos que desenvolvi durante minha trajetória de aprendizado:

- **NEXUS TECH:** plataforma de e-commerce com sistema de usuários, produtos, carrinho e gerenciamento de pedidos.
- **GymTracker:** aplicação voltada ao acompanhamento e gerenciamento de treinos.
- **AtacaTudo:** sistema de gerenciamento de estoque.
- **Sistema de Reservas:** aplicação para gerenciamento de reservas de laboratórios.

## Funcionalidades

- Apresentação pessoal e acadêmica.
- Seção de conhecimentos e tecnologias.
- Exibição de projetos desenvolvidos.
- Apresentação de cursos e certificações.
- Formulário de contato.
- Painel administrativo para gerenciamento de mensagens.
- Pesquisa e filtros de mensagens.
- Criação, edição, alteração de status e exclusão de registros.
- Layout responsivo para diferentes dispositivos.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador ou utilize a extensão Live Server do Visual Studio Code.
4. Para acessar a área administrativa, abra o arquivo `admin.html`.

Não é necessário instalar Node.js ou configurar um banco de dados para executar a versão demonstrativa.

## Painel administrativo

O projeto possui uma área administrativa acessível pelo arquivo `admin.html`.

Nela é possível visualizar, pesquisar, filtrar, cadastrar, editar, alterar o status e excluir mensagens recebidas.

**Armazenamento:** nesta versão, os registros são armazenados no LocalStorage do navegador. Isso significa que os dados ficam disponíveis apenas no navegador e dispositivo utilizados.

O painel é demonstrativo. Para utilização em produção, seria necessário implementar um backend e um sistema de autenticação seguro.

## Integração com EmailJS

O formulário de contato possui uma integração opcional com EmailJS, preparada para:

- Enviar notificações ao responsável pelo portfólio.
- Enviar confirmações para quem preencher o formulário.

Para ativar o serviço, é necessário configurar uma conta no [EmailJS](https://www.emailjs.com/) e preencher as informações de integração no arquivo `script.js`.
